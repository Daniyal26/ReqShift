THE PROBLEM

Requirements describe behavior. Counts often come later.

Robots, controllers and other components may vary in number from one build to the next. When specifications leave those quantities open, teams need to reason through the combinations themselves. ReqShift helps make those choices checkable.

HOW IT WORKS

From specification to analysis.

01

Extract

Create a goal model from the document, with each element linked to its source.

02

Review

An engineer checks the model and supplies quantities the document leaves open.

03

Analyze

GoalShift checks the allowed configurations and reports the outcomes.

A CLEAR DIVISION OF WORK

AI helps read the document. It doesn’t decide the result.

The extracted model is a draft for an engineer to review. GoalShift computes the findings from that model; AI is not part of the proving step.
